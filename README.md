A tiny Python 3.13 program that writes a single one-line joke, about reviewing a pull request written by an AI coding agent, to `/output/entry.txt` for make.fun's comedy-judge bounty. It collapses white space to keep the joke on one line and refuses anything over 280 characters.

## Run it

```sh
python3 main.py --out ./output && cat ./output/entry.txt
```

The grader runs `python3 main.py` with no arguments, which writes `/output/entry.txt`.
